# Research

Facts collected before decisions — what each candidate technique, model, codebase and dataset actually does, what it needs, and how it's licensed. The architecture docs under [../architecture/](../architecture/_index.md) are set aside for this exploration, not superseded; nothing in them changes because of what's recorded here until a decision is made and written there.

One doc per topic under investigation, plus a problem-statement doc framing the questions the collection answers, and a proposal doc when one emerges — mark it clearly as **proposal, partly decided** so it can't be mistaken for settled design. Sources for every claim live in [../references/research-sources.md](../references/research-sources.md), grouped by the same topics.
